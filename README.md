# Français Villageois — мод для Minecraft 1.21.8 (Fabric)

Мод на основе датапака **Français Villageois 3**: датапак встроен в мод без изменений, кроме одного — обычный ПКМ открывает его викторину, а **Shift + ПКМ** теперь открывает окно свободного разговора.

Всё работает автономно, на правилах и алгоритмах: без ИИ, без интернета, без внешних сервисов. Мод рассчитан на одиночную игру.

## Установка

1. Установи **Fabric Loader** для Minecraft **1.21.8** и мод **Fabric API**.
2. Положи `francais-villageois-1.0.0.jar` в папку `mods`.
3. Если в мире стоит zip-датапак Français Villageois, удали его из папки `datapacks`: мод уже содержит его.

Готовый jar собирает GitHub Actions (вкладка **Actions** → последний запуск → артефакт `francais-villageois-mod`). Собрать локально: `./gradlew build`, jar появится в `build/libs/`.

## Управление

| Действие | Что происходит |
|---|---|
| ПКМ по жителю | урок-викторина датапака (как раньше) |
| **Shift + ПКМ пустой рукой** по жителю | окно разговора: поле для текста на французском, житель отвечает |
| **Shift + ПКМ с предметом** по жителю | отдать предмет для поручения «Apporte-moi…» |
| **Shift + ПКМ по пюпитру** | библиотека |
| **Shift + ПКМ по колоколу** | мэрия, доска поручений |
| `/frv` | справка |
| `/frv journal` | слухи, клады, подслушанные разговоры, задания мэрии |
| `/frv carnet` | как жители тебя поправляли |
| `/frv amis` | дружба с жителями |
| `/frv ru` | показывать перевод под репликами (по умолчанию только при наведении) |
| `/frv chat off` / `on` | выключить или включить чат деревни |

## Места

- **Le Café.** Кафе — это любой **костёр** в деревне. У костра жители болтают охотнее (дружба растёт вдвое быстрее), а в их разговорах между собой всплывают слухи о сундуках: *« Il y a un coffre à vingt-trois blocs au nord du feu de camp ! »*. Сундук действительно ставится в мир туда, куда указывает фраза. Понял число и сторону света — нашёл клад.
- **La Bibliothèque.** Shift + ПКМ по пюпитру. Девять адаптированных текстов (A1, A2, B1), после каждого четыре утверждения: *vrai / faux / le texte ne le dit pas*, с объяснением. За первое прочтение — изумруды.
- **Le Marché.** По субботам (раз в 7 игровых дней) ярмарка. Торговцы выкрикивают цены над головой и в чат, со звуками жителей. В окне разговора появляется кнопка «Marchander»: торгуйся текстом — *« C'est trop cher ! Trois, ça va ? »*. Числа понимаются и словами, и цифрами; вежливость (*s'il vous plaît*) снижает цену.
- **La Mairie.** Shift + ПКМ по колоколу. Объявления только на французском: *« Il faut dix bûches de chêne pour le pont. »* Если принесёшь не тот сорт, мэрия подскажет.

## Жители

- **Поручения.** Спроси *« Tu as besoin d'aide ? »* и услышишь, например, *« Apporte-moi trois pommes rouges »*. Возьми предметы в руку и нажми Shift + ПКМ. Житель проверит сорт, цвет и количество. Перевода у поручения нет, подсказка появляется только после двух неудачных попыток.
- **Отношения.** Дружба растёт от разговоров (до +8 в день), поручений, цветов в подарок и праздников. С 50 житель предлагает перейти на «tu», и это синхронизируется с викторинами датапака. С 65 зовёт на субботний праздник у колокола (фейерверк, музыка). С 80 делится секретом: иногда смешным, иногда с настоящим кладом.
- **Смена дня.** Утром *Bonjour*, вечером *Bonsoir*, ночью *« Pourquoi tu ne dors pas ? »*, в дождь жалобы на погоду. Скажешь вечером «Bonjour», и житель ответит **Bonsoir**.
- **Исправление как у живого учителя (recast).** Житель не пишет «ошибка», а переспрашивает правильно: *« je veux fromage »* → *« Ah, tu veux **du fromage** ? D'accord ! »*. Правила покрывают артикли (du / de la / des, le / la, un / une), род, слияния (au, du), elision (j'aime), *avoir* вместо *être* (j'ai 20 ans, j'ai faim), *je suis allé*, *il pleut*, *je vais bien*. Все исправления собираются в `/frv carnet`.
- **Память.** Житель запоминает имя, работу, любимую еду, город и возраст: *« Je m'appelle Anna, je suis professeur »*. На следующий игровой день он спросит: *« Alors, ton travail à l'école, ça va ? »*
- **Чат деревни.** Жители переписываются между собой с юмором: админ чата — кот Moustache, коза Biscotte стала модератором, у Голема «ржавчина», а не смущение. Чат не спамит: не чаще раза в 5–9 минут, не больше 3 переписок за игровые сутки, темы не повторяются два дня и зависят от времени, погоды и ярмарки. На твои поступки (перепутал яблоки, сторговался, нашёл клад) деревня реагирует в том же ритме.
- **Подслушанные разговоры.** Жители, стоящие рядом, болтают друг с другом, реплики всплывают над головами. Все реплики записываются в `/frv journal`, перевод виден при наведении.

## Устройство проекта

- `src/main/resources/resourcepacks/francais_villageois/`: встроенный датапак.
- `fr.villageois.lang.Lang`: языковое ядро (recast, числа словами, память, намерения).
- `fr.villageois.brain.Brain`: локальный «мозг» жителя.
- `fr.villageois.content`: все тексты, юмор, книги, поручения, правила чата.
- `Talk`, `Market`, `Places`, `Ambient`, `Treasure`: игровые системы. Всё выполняется ванильными командами и окнами-диалогами 1.21.6+.
- Прогресс хранится в папке мира: `francais_villageois.json`.
